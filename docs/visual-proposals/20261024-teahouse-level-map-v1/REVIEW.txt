ROZSAH
Jde o izolovaný vizuální návrh. Celá složka je pod .gdignore.
Produkční scény, navigace, herní pravidla, Android, GitHub ani
schválené referenční obrázky se nemění. Žádný release nevznikl.
Předchozí návrh garden-teahouse-loop-v1 zůstává oddělený a není integrován.

Stav 160 mincí, 8/30 hvězd a úroveň 4 jsou ukázkové hodnoty.
30 mincí + 2 semínka meduňky za úroveň a 40 mincí za úkol jsou
návrhové částky, nikoli schválené vyvážení ekonomiky.
Deset očíslovaných zastávek není deset dokončených herních úrovní.
Trvalý postup, odměny, opakované výhry a nové úkoly nejsou implementovány.
Zakoupené dekorace ani hráčova uložená data návrh nečte a nepřepisuje.

Klikací prototyp: Spustit-navrh.ps1 (Godot 4.7, izolované APPDATA).
Fungují obě záložky, detail dostupné/zamčené úrovně, detail úkolu,
okno výrobků a zavírání. Tlačítko HRÁT otevře stávající samostatnou
spojovací minihru jako ukázku návaznosti, bez zásob a udělování odměn.
Výběr úrovní zatím nevolí deset různých pravidel. Výsledkový snímek
je vizuální návrh, nikoli důkaz získání odměn či uloženého postupu.
