# Čajovna v5 – výtvarný návrh prostředí

Majitel schválil průběh v4, ale celkový vzhled nadále považuje za nedokončený.
Tento samostatný statický návrh vznikl vestavěným imagegen, není snímkem běžící nové verze.

Návrh propojuje scénu světlem od okna, medovým dřevem, papírovými recepty a zelenou vložkou bylinkového tácu.
Několik pomůcek a látka zůstávají u vnějších hran, aby střed patřil bylinkám a ovládání.

Obrázek má šest řádků po šesti polích. Vygenerovaná skladba bylinek a drobné texty jsou pouze ilustrativní:
při případné implementaci musí zůstat skutečná deska, původní české texty, počty, pravidla a geometrie ovládání z kódu v4.
Stejný výtvarný směr by následně dostala scéna nalévání. Nový návrh nalévání zatím nevznikl.

Předloha: ../20261021-teahouse-prototype-v4/spojovani.png.
Přesná zadání jsou v imagegen.prompt.txt a refinement.prompt.txt.
Vybraný návrh: cajovna-v5-vytvarny-navrh.png. Stav schválení a hash: review-status.json.

Zdroj schváleného prototypu v4 je beze změny podle porovnání všech souborů s jeho archivem.
Nebyly měněny běžící hra, uložený postup, exporty ani schválené vizuální reference. Funkční testy se pro statický návrh znovu nespouštěly.
