# Čistší spodní část čajovny

Uživatel schválil odstranit přepínače testovacích receptů, technický řádek prototypu a trvalý drobný návod.

Výtvarný návrh 5a: cajovna-v5a-cistsi-ovladani.png, upravený vestavěným imagegen.
Přesné zadání: imagegen.prompt.txt. Jde o statickou ilustraci, není to snímek nového prostředí běžícího ve hře.
Původní návrh 5 zůstal zachovaný v sousedním adresáři.

Hratelný prototyp 4.1: source-v4.1/ je neměnný archiv zdrojů tohoto kroku.
Přepínače receptů nejsou vytvořené, ani skryté v tab pořadí. Další recept nabízí příští objednávka.
Úvodní návod je zobrazen jednou po dobu otevřené samostatné scény. Restart a nová objednávka ho nevrací.
Požadovaná nápověda znovu vysvětlí spojování i šikmo a označí legální cestu zdarma.
Dočasné zprávy k tahu zůstávají. Prázdný stavový panel ani stálý text se nekreslí.
Malovaný návrh prostředí 5a zatím není integrovaný; native snímky runtime-* zachycují skutečný prototyp.

Prošlo 594 nativních kontrol: ovládání na třech rozlišeních, jednorázové intro,
restart, nápověda, fokus, průchod všemi třemi recepty skutečnými gesty a dalšími objednávkami.
Původní hra: 7 955 kontrol a všech 34 schválených vizuálních bran prošlo.
54 referenčních hashů je stejných jako v předchozí etapě, capture stderr prázdný.
175 souborů ověřeného mirroru se shoduje se zdrojem. Pravidla, skórování, model,
původní animované assety a hráčské savy se neměnily. Test telefonu, publikování a release nebyly součástí kroku.
