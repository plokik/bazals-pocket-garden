# Myška: čtyři běžecké snímky

Vygenerováno vestavěným imagegen s průhledným pozadím. Jediný produkční PNG; původní atlas kocoura sloužil výhradně jako stylová reference a zůstal nezměněn.

Use case: illustration-story. Production game sprite sheet, ONE transparent PNG asset. Reference image is STYLE ONLY: match its hand-painted cozy garden mobile game illustration, warm detailed fur, subtle dark brown outline, crisp cartoon anatomy, gentle highlighted shading. Create ONE tiny friendly brown-grey field mouse with cream tummy, soft pink rounded ears and nose, black shiny eyes, long thin curved tail. Four equally sized side-view running animation frames in ONE HORIZONTAL ROW, all facing right, all same character size, baseline and camera. Legs alternate reach / tuck / spring / land with slight natural changes, NOT four different mice. Mouse occupies middle 70% of each of four equal-width cells, generous completely transparent padding between frames and around whole sheet; complete tail and whiskers entirely visible inside each cell, no cropped features. Canvas aspect ratio 3:1. Genuinely transparent background, no ground, no shadows baked in, no grass, no props, no cat, no text, no letters, no numbered cells, no borders. Cute believable field mouse, painted in same world as orange garden cat. Final sheet will animate at small mobile size, use readable silhouette.
